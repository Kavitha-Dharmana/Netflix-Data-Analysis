# Netflix Movies and TV Shows Analysis

## Project Overview
This project analyzes Netflix movies and TV shows using Python and Pandas. It explores content types, release years, ratings, countries, genres, and durations.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- VS Code

## Key Analysis
- Movies vs TV Shows comparison
- Missing values analysis
- Content release year trends
- Content ratings distribution
- Top 10 countries
- Top 10 genres
- Movie duration and TV show seasons

## Dataset
Netflix Movies and TV Shows dataset (`netflix_titles.csv`).

## How to Run
1. Download the dataset and place it inside the `data` folder.
2. Open `netflix_analysis.ipynb` in VS Code.
3. Run the notebook cells from top to bottom.

## Conclusion
This project explores Netflix's content library and identifies patterns in content types, genres, ratings, release years, and country distribution.
